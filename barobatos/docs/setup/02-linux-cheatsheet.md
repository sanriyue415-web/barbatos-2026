# W1 D2: Linux 基础命令 Cheatsheet
日期: 2026-07-20
## 12 个必会命令

### 导航
  - `pwd`  当前所在路径
  - `ls` / `ls -la`  列目录（-a 显示隐藏文件，-l 长格式）
  - `cd 目录`  切换目录；`cd ~` 回家，`cd ..` 上一级，`cd` 不带参数也回家
### 操作
  - `mkdir 目录`  建目录；`mkdir -p a/b/c` 递归建多层（前边没有的一起建了）
  - `touch 文件`  建空文件；多个空格分隔可批量建（如 touch 1.txt 2.txt）
  - `cp 源 目标`  复制；`cp -r` 复制目录(如 cp 1/2/3/4.txt 5/6/)
  - `mv 源 目标`  移动或重命名 (重命名：mv name-a name-b 移动：mv 文件1 目录名/)
  - `rm 文件`  删除；`rm -r 目录` 删目录（无回收站，慎用）
### 查看
  - `cat 文件`  全部输出
  - `less 文件`  分页浏览（`q` 退出）
  - `head -n N 文件`  前 N 行；`tail -n N 文件` 后 N 行
  - `grep 模式 文件`  搜索文本；`-i` 大小写不敏感
  - `find 目录 -name '模式'`  按文件名搜索
### 组合
  - `A | B`  管道，A 的输出喂给 B
  - `A > 文件`  重定向（覆盖）
  - `A >> 文件`  追加
  - `chmod +x 文件`  加执行权限
## 三个特殊路径符号

  - `~`  家目录 /home/sanriyue
  - `.`  当前目录
  - `..` 上一级
## 绝对路径 vs 相对路径

  - `/` 开头 = 绝对路径（从根开始）
  - 不以 `/` 开头 = 相对路径（从当前目录开始）
## 救命键

  - `Ctrl+C`  中断当前命令（万能救命键）
  - `Ctrl+D`  发送 EOF（结束 stdin 输入）
  - Tab      自动补全路径 / 文件名，永远用它避免打错
  - Tab Tab  列出所有候选
## D2 踩的坑

  1. `cd~` 中间必须有空格，`cd ~`
  2. 绝对路径开头的 `/` 和相对路径的区别，栽在 `cd /level1` 上过
  3. grep 少写搜索模式导致命令卡住，`Ctrl+C` 救回来
  4. `~xxx` 没斜杠会被理解为"别人的家目录"，只有 `~` 或 `~/xxx` 正确
## 感受

  1. Tab键补全非常方便
  2. 做大改动时要先备份，防止事故的发生
