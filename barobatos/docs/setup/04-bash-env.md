# D4 bash learning
日期： 2026-07-22
## PATH
 - 执行程序时，系统会依次从PATH中寻找，没有就报错
 - 查询PATH：$PATH
 - PATH中的冒号是每个文件夹的分隔
## .bashrc程序
 - 在桌面终端打开时默认加载
 - 修改完.bashrc文件后不会立刻生效，source ~/.bashrc 会立刻更新并启用
## echo中引号的区别
 - ''中的命令不会被展开，视为字符串
 - ""中的命令会被识别并运行
## 执行命令
 - ;为一起执行，无论成功与否
 - &&为前一条命令执行成功才会执行后一条，适用于有前后关系的命令
 - 换行 为相互独立去执行，类似于;
## bash中的注释
 - bash将#设置为注释符，不会被执行
## alias的用法
 - 临时启用--直接在终端中 alias xx ='xx xxx'
 - 永久启用--由于.bashrc的特性，可在.bashrc中加入alias xx ='xx xxx'使之每次自动执行
