### D5 — lambda（周五，加量）

关键语法：`[捕获](参数) -> 返回类型 { 函数体 }`

必做：
- 写一个最简 lambda 并立即调用
- 捕获实验：`[]`（不捕获）、`[x]`（值捕获）、`[&x]`（引用捕获）—— 三种各写一次，观察修改 x 后的行为
- `std::function<void(double)>` 存一个 lambda，然后调用它
- **重点**：给 sensor 注册回调 —— `void set_callback(std::function<void(double)> cb)`，`read()` 时触发回调

这是 ROS 订阅者的**真实模式**：
```
sub = create_subscription<msg>("topic", 10, [](msg::SharedPtr m) { ... });
```
写完 D5 你就能读懂这行了。

**必须回答**：
1. 值捕获 `[x]` 和引用捕获 `[&x]` 什么时候必须用哪个
2. `std::function` 和函数指针差别（提示：函数指针能捕获变量吗）
3. 为什么 lambda 比单独写个函数方便

### D6 — CMake 三件套（周六）

目标：把 sensor 编译成**库**，main 链接它。目录结构：

```
12-cmake-project/
├── CMakeLists.txt          ← 顶层
├── src/
│   ├── CMakeLists.txt      ← 子目录
│   ├── sensor.h
│   ├── temperature_sensor.h/.cpp
│   └── distance_sensor.h/.cpp
└── app/
    ├── CMakeLists.txt
    └── main.cpp
```

三件套：
- `add_library(sensors temperature_sensor.cpp distance_sensor.cpp)`
- `target_include_directories(sensors PUBLIC ${CMAKE_CURRENT_SOURCE_DIR})`
- `target_link_libraries(app PRIVATE sensors)`

外加 `add_subdirectory(src)` / `add_subdirectory(app)`

**必须回答**：
1. `add_library` 和 `add_executable` 差别
2. `PUBLIC` / `PRIVATE` 在 `target_include_directories` 里什么意思
3. 故意漏掉 `target_link_libraries`，读报错 —— 和 W2 D5 那个 `undefined reference` 是同一类吗

**这一天最重要**：ROS 包的 CMakeLists 就是这个结构。W4 装完 ROS 你会立刻认出来。
